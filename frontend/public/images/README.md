# Image credits

- `sports-courts.webp` — optimized from “aerial photography of basketball court” by CHUTTERSNAP on [Unsplash](https://unsplash.com/photos/u-Qgv9qY48Q). Used under the Unsplash License.
- `badminton-racket.webp` — optimized from “Shuttlecock on Badminton Racket” by Anurag Sharma on [Pexels](https://www.pexels.com/photo/shuttlecock-on-badminton-racket-13701956/). Free to use under the Pexels License.

These photographs provide general sports context. They do not depict venues contained in the historical dataset.

The four SVG visual guides (`activities.svg`, `source-regions.svg`, `data-lineage.svg` and `community-review.svg`) are original project illustrations. They are intentionally small, reused where appropriate and loaded lazily so additional visual context does not materially increase page weight.

The original JPEG source files are retained outside the deployable `public` directory in `docs/image-sources/`. The two WebP files loaded by the overview are resized and compressed to reduce their combined transfer size by about 60%.
